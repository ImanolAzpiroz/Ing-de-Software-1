# Parte I Definiciones

## 1) Que es un requeriemiento?

Termino para referirse a las necesidades del cliente. Es una caracteristica del sistema o una descripcion de algo que el sistema es capaz de hacer con el objeto de satisfacer el proposito del sistema.

## 2) Requerimientos funcionales y no funcionales
- Requerimientos funcionales: 
    Interaccion entre el sistema y su ambiente.
    Como debe comportarse a determinado estimulo.
    Descripcion de lo que el sistema puede y no puede hacer.
    Descripcion de su funcionalidad.

- Requerimientos no funcionales:
    Resstriccion sobre el sistema que limita nuestras elecciones en la construccion de una solucion.


## 3) Stakeholder?

Hace referencia a cualquier persona o grupo que se verá afectado por el sistema, directa o indirectamente.

- Usuarios finales
- Ingenieros
- Gerentes
- Expertos del dominio

## 4) Comunicacion
La comunicacion es la base para obtener las necesidades de un cliente.
Es tambien la principal fuente de error

### Fuentes para obtener la informacion
 - Documentacion
 - Stakeholders
 - Especificaciones de sistemas similares

## 5) Puntos de vista

- Interactuadores: Representan a las personas u otros sistemas que interactuan directamente con el sistema. Pueden influir en los requerimientos del sistema de algun modo.

- Indirecto: Representan a los stakeholders que no utilizan el sistema ellos mismo pero que influyen en los requerimientos de algun modo.

- Dominio: Representan las caracteristicas y reestricciones del dominio que influyen en los requerimientos.

## 6) Problemas de comunicacion
- Dificultades para expresar claramente las necesidades
- No ser conciente de sus propias necesidades
- No entender como la tecnologia puede ayudar
- Medios de comunicacion inadecuados
- Miedo a parecer incompetente por ignorancia a la tecnologia
